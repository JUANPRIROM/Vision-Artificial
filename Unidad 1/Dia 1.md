Se debe de tener el 80% de asistencia para poder hacer examen.

Objetivo: Desarrollar y utilizar sistemas de visión embebidos que incluyan aprendizaje de máquina que puedan ser aplicados en la diversidad de áreas de aplicación de sistemas de visión artificial.

Competencias: 
- Comprender la arquitectura de un sistema de visión artificial y el procesamiento digital de imágenes.
- Conocer la arquitectura y estructura de un sistema de visión que se utiliza en la industria.
- Adquirir conocimiento básico de algoritmos de visión artificial para una aplicación especifica. 

Temario:
Unidad 1 (Sistemas de visión y procesamiento digital de imágenes)
- 1.1 Introducción de los sistemas de visión.
- 1.2 Componentes de un sistema de visión.
- 1.3 Conceptos básicos sobre imágenes.
- 1.4 Operaciones básicas con imágenes.

Unidad 2 (Sistemas de visión)
- 2.1 Arquitectura de un sistema de visión.
- 2.2 Tecnologías de sistemas embebidos.
- 2.3 Análisis de un sistema de visión embebido.
- 2.3.1 Ambiente de desarrollo.
- 2.3.2 Operadores
- 2.3.3 Generación  de una aplicación. 
- 2.3 Gestión de Proyecto de sistema de visión.

Unidad 3 (Procesamiento de imágenes y video)
- 3.1 Manejo de contraste
- 3.2 Segmentación (bordes, regiones, color, textura)
- 3.3 Análisis morfológico
- 3.4 Flujo óptico
- 3.5 Desarrollo de una aplicación
